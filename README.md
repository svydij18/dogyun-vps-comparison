## 怎么算"便宜"：选便宜VPS前先想清楚5件事

在写狗云之前，先把"2026便宜VPS"这件事的避坑逻辑摊开。这些年我看过太多人图便宜买了VPS，最后花了更多钱在补救上。整理五条经验：

1. **线路比配置更值钱**。一个1核1G的小机器，如果走的是CN2 GIA或CMI优化线路，访问体验秒杀一个4核8G却走普通国际线路的。买之前一定问清楚走什么线。
2. **流量计费方式要算清**。包月固定流量 vs 按GB计费，差异巨大。访问量稳定选包月，访问量忽高忽低选按量。
3. **续费价格不一定等于首单价格**。很多商家首年便宜、续费翻倍。买之前看清楚续费价。
4. **退款政策是底线**。便宜VPS怕跑路，能退款、能原路退回余额的，至少多一层安全垫。
5. **小时计费是个被低估的省钱利器**。如果你的负载不是24小时满载，按时计费能省下一大笔。这点正是狗云的招牌之一。

## 狗云是谁：从虚拟主机到"国人云"的小历史

狗云（DogYun）的母公司早在2012年就开始做虚拟主机，2014年进入云服务器领域，2019年正式启用"狗云"这个新品牌。算下来，这个团队在主机行业摸爬滚打了十几年，不是那种一夜冒出来的新玩家。

定位上狗云很"国产"：控制面板是简体中文自主研发的"Dudu面板"，工单24小时有人盯（有用户反馈凌晨发工单也有人回），支付走支付宝和微信，价格以人民币结算，主战场是香港、韩国、日本、美国、重庆等机房，线路针对国内做了优化（CN2 GIA、CMI、CU、AS9929等都有覆盖）。

一句话总结：狗云是面向国内用户、把"中文友好+按需付费"做到极致的那一类云商家。它不是最便宜的（Virmach那种白菜价它学不来），也不是最贵的，胜在"算得清楚、用得灵活"。

## 两条产品线：弹性云 vs 经典云，本质是两种省钱逻辑

狗云把产品分成两条线，理解这两条线是看懂"狗云怎么便宜"的关键：

- **弹性云服务器**：自定义配置、按时/按月计费、随开随停、随时升降配、可暂停只扣硬盘费、可自助更换IP、可切换线路。本质上是个"按需付费的云"。
- **经典云服务器**：固定配置、包年包月、开通后不能改配置、价格更便宜。本质上就是"传统的固定套餐VPS"。

简单说：**临时项目、突发需求、想试水就选弹性云；长期稳定跑一个站、追求单价最低就选经典云。**

下面这张对比表把两条线的差异拉直了看：

| 维度 | 弹性云 | 经典云 |
| --- | --- | --- |
| 配置 | 自定义（CPU/内存/硬盘/带宽/线路） | 固定套餐 |
| 计费 | 按小时或按月 | 包年包月 |
| 升降配 | 随时 | 不支持 |
| 暂停 | 支持（只扣硬盘和IP费） | 不支持 |
| 切换线路 | 多线路机房支持 | 不支持 |
| 单价 | 略高 | 更低 |
| 退款 | 余额一个月内原路退回 | 三日内可销毁退款（条件限制） |
| 适合 | 临时编译、测试、流量不稳的项目 | 长期建站、固定业务 |

如果你脑子里已经有"长期建一个站"的画面，往下看经典云的套餐表；如果你的项目还没定型，先看弹性云。
